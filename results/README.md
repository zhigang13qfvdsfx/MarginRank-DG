# Curated aggregate results

This directory contains the minimal aggregate outputs needed to audit the
manuscript's final v4 claims:

- development-domain and fixed-configuration discrimination;
- missingness robustness;
- frozen coefficients;
- PACA-CA model, subgroup, and time-dependent metrics;
- architecture ablation;
- GSE77435 and PRINCE stress-test summaries;
- single-cell cell-type summaries;
- pathway enrichment;
- post-freeze anti-overfitting diagnostics;
- machine-readable gate reports.

Individual-level predictions, raw clinical records, patient-level pseudobulks,
and large bootstrap, permutation, or missingness replicate tables are excluded.
They can be regenerated only after the source datasets have been obtained under
their original access conditions.
