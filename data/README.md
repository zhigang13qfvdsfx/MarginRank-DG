# Local data directory

Raw and processed cohort data are intentionally absent from the repository.

After obtaining data from the original providers, place locally prepared
analysis inputs under:

```text
data/processed/
```

The analysis scripts document the expected filenames and schemas for each
cohort. Do not commit raw matrices, controlled-access files, donor identifiers,
or individual-level predictions.

See `../DATA_AVAILABILITY.md` for accessions and release boundaries.
